## basic linux commands

## check current directory`
``` pwd

## list files and directory
``` ls

## list all files including hidden files
``` ls-la

## change directory
``` cd

## create directory
``` mkdir my-folder

## remove an empty directory
``` rmdir my-folder

## create a file
``` touch file.txt

## copy a file 
``` cp file.txt backup.txt

## move or rename a file
``` mv file.txt newfile.txt

## delete a file 
``` rm file.txt
