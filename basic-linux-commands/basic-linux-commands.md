# Basic Linux Commands

## Check current directory
```bash
pwd
```

## List files
```bash
ls
```

## List hidden files
```bash
ls -a
```

## Long listing
```bash
ls -l
```

## Change directory
```bash
cd
```

## Create a directory
```bash
mkdir project
```

## Remove a directory
```bash
rmdir project
```

## Create a file
```bash
touch file.txt
```

## Copy a file
```bash
cp file.txt backup.txt
```

## Move or rename a file
```bash
mv file.txt documents/
```

## Delete a file
```bash
rm file.txt
```
